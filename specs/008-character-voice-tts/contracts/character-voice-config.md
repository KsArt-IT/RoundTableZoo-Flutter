# Contract: голос персонажа в `assets/characters/characters.json`

Расширение существующего контракта `specs/004-table-screen/contracts/character-config.md`.
Ничего из уже описанного там не меняется — добавляется одно необязательное поле.

---

## 1. Формат

```jsonc
{
  "id": "cat",
  "emoji": "🐱",
  "name": "Кот",
  "colorHex": "#8A7CA8",
  "fallbackReply": "Мр-р. Слов нет — но я тебя услышал.",
  "maxReplyLength": 220,
  "voice": { "pitch": 1.5, "rate": 0.62 }   // ← новое, необязательное
}
```

| Ключ | Тип | Обязателен | Диапазон | Поведение при нарушении |
|---|---|---|---|---|
| `voice` | object | нет | — | отсутствует или не объект → `CharacterVoice.neutral` (1.0 / 0.5) |
| `voice.pitch` | number | нет | 0.5 … 2.0 | отсутствует/не число → 1.0; вне диапазона → зажимается |
| `voice.rate` | number | нет | 0.0 … 1.0 | отсутствует/не число → 0.5; вне диапазона → зажимается |

**Почему всё необязательное и ничего не бросает**: та же линия, что у `emoji` в контракте 004 —
неполный или подпорченный конфиг обязан деградировать до нейтрального звучания, а не ронять
загрузку каталога (иначе сломанное поле голоса обнулит весь стол — `TableState.error`).
`FormatException` парсер бросает по-прежнему только на ключах, без которых персонаж не существует
(`id`, `name`, `colorHex`, `fallbackReply`, `maxReplyLength`).

---

## 2. Стартовые значения (FR-003)

| id | pitch | rate | Как звучит |
|---|---|---|---|
| `cat` | 1.50 | 0.62 | самый высокий, самый быстрый |
| `dog` | 1.15 | 0.56 | средний по высоте, заметно бодрее среднего темпа |
| `crocodile` | 0.85 | 0.46 | низкий, медленный |
| `hippo` | 0.70 | 0.40 | самый низкий, самый медленный |

Инвариант, который проверяется юнит-тестом на самом ассете:
`pitch(cat) > pitch(dog) > pitch(crocodile) > pitch(hippo)` и
`rate(cat) > rate(dog) > rate(crocodile) > rate(hippo)`.

---

## 3. Единицы измерения

- `pitch` уходит в `FlutterTts.setPitch` как есть; 1.0 — обычная высота на обеих платформах.
- `rate` уходит в `FlutterTts.setSpeechRate` как есть; 0.5 — обычный темп: Android-реализация
  плагина домножает значение на 2.0 перед `TextToSpeech.setSpeechRate`, iOS использует шкалу
  `AVSpeechUtterance` с той же нормой.

Значения намеренно платформенно-нейтральны: конфиг один на Android и iOS, без веток.

---

## 4. FR-004: изменение без правок кода

Достаточное условие — парсер читает `voice` из ассета и передаёт его в `SpeechRequest` без
промежуточных констант. Проверка (описана в `quickstart.md`): изменить `voice.pitch` у любого
зверя, `flutter run` без пересборки Dart-логики (hot restart), услышать другое звучание.
