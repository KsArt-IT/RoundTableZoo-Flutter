# Quickstart — проверка экрана «Стол»

**Feature**: `specs/004-table-screen` | Все команды выполняются из `app/`.

Документ отвечает на один вопрос: как убедиться, что фича работает. Детали контрактов — в
`contracts/`, модель состояния — в `data-model.md`.

---

## 0. Предусловия

```bash
cd app
flutter pub get
dart run build_runner build --delete-conflicting-outputs   # freezed + injectable + drift + json
flutter gen-l10n                                            # после правки ARB
```

Кодогенерация обязательна после любых изменений `@freezed`, `@injectable`, `@JsonSerializable`
(рабочий процесс, п. 4 конституции).

## 1. Gate перед сдачей задачи

```bash
flutter analyze          # без ошибок и без deprecated_member_use
flutter test             # полностью зелёный
```

Задача с падающими тестами не считается выполненной (рабочий процесс, п. 5).

Полезные точечные прогоны:

```bash
flutter test test/presentation/table_cubit_test.dart
flutter test test/widget/table_page_test.dart test/widget/table_accessibility_test.dart
```

## 2. Ручной прогон без прокси (US1–US5 на заглушке)

```bash
flutter run                      # PROXY_BASE_URL пуст → StubAiProxyClient (contracts/ai-proxy-client.md §6)
```

| Шаг | Ожидаемый результат | Требование |
|---|---|---|

| Тапнуть по зверю, ничего не заполнив | Запрос не уходит; видно, чего не хватает | FR-014 |
| Выбрать эмодзи | Выбор выделен формой, не только цветом; запись дня создана | FR-001, FR-002 |
| Перейти на «Дневник» и обратно | Эмодзи и текст на месте | FR-003 |
| Ввести текст, подождать секунду, свернуть и вернуть приложение | Текст на месте | FR-008a, SC-009 |
| Тапнуть по зверю | ~1.2 с видимое ожидание, затем реплика проявляется посимвольно | FR-016, FR-017 |
| Тапнуть по баблу во время проявления | Текст сразу целиком | FR-017a |
| Тапнуть по второму зверю, не дожидаясь первого | Оба отвечают независимо | FR-019 |
| Тапнуть по тому же зверю дважды подряд | Остаётся ответ последнего тапа | FR-020, SC-004 |

## 3. Проверка пяти отказов AI (US4)

Заглушка умеет вернуть любой отказ (`contracts/ai-proxy-client.md` §6) — сценарий задаётся перед
тапом из отладочной точки, аналогично `DebugFailureInjector`.

| Отказ | Ожидаемое поведение | Требование |
|---|---|---|
| `network` | Сообщение про сеть рядом со столом; шкала эмодзи работает | FR-024, FR-028 |
| `rateLimited` | Отдельный текст про лимит на сегодня | FR-025 |
| `aiDisabled` | «AI временно недоступен»; отметка настроения доступна | FR-026 |
| `invalidResponse` | Заготовленная реплика зверя в бабле, помечена как не настоящий ответ | FR-027 |
| `timeout` (сервис молчит) | Через ~15 с то же, что при `invalidResponse` — «вечного ожидания» нет | FR-027a, FR-027b |

Проверка «нет сети» без заглушки: включить авиарежим на устройстве и тапнуть по зверю.

## 4. Проверка против реального прокси (когда он появится)

```bash
flutter run --dart-define=PROXY_BASE_URL=https://<адрес-прокси>
```

Ожидание: те же сценарии §2 проходят, реплики разных зверей звучат по-разному (SC-003 — критерий
этой проверки, не текущего среза).

| Шаг | Ожидаемый результат | Требование |
|---|---|---|
| Ввести текст на русском и опросить всех зверей | Все реплики на русском, текст не переписан и не переведён интерфейсом | FR-022 |
| Один текст, все четыре зверя | Не менее чем 2 из 3 оценщиков относят минимум два ответа к разным по тону | SC-003 |

Запрос в этой фазе уходит **без** токена подлинности — это ожидаемо и закрывается фазой прокси.

## 5. Офлайн-ядро (US1)

```bash
# на устройстве: включить авиарежим
```

Отметка настроения, ввод текста и их восстановление обязаны работать полностью (SC-002); ни одного
сообщения о сети при работе только со шкалой быть не должно.

## 6. Режим «только чтение»

Воспроизводится через `DebugFailureInjector` (`storageUnavailable` при старте) → на экране
восстановления выбрать «продолжить без сохранения».

Ожидание: баннер режима виден, отметка не сохраняется с понятным сообщением, тап по зверю не
уходит в сеть (FR-032).

## 7. Доступность и производительность

```bash
flutter test test/widget/table_accessibility_test.dart
```

Проверяется автоматически: `meetsGuideline(labeledTapTargetGuideline)`,
`meetsGuideline(androidTapTargetGuideline)`, наличие метки состояния у каждого зверя (SC-008).

Вручную на среднем устройстве: 4–6 зверей в покое, 60 секунд наблюдения без заметных рывков
(SC-006); при включённом системном «уменьшить движение» реплика показывается сразу целиком.
