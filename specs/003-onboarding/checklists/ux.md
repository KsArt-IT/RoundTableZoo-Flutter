# UX & Accessibility Requirements Checklist: Онбординг — первый запуск

**Purpose**: Проверить качество формулировок требований к экрану, текстам, локализации и
доступности — не работу реализации, а то, достаточно ли однозначно написана сама спека.
**Created**: 2026-08-16
**Feature**: [spec.md](../spec.md)
**Audience / timing**: автор, перед `/speckit-tasks`

## Requirement Completeness

- [x] CHK001 Задан ли обязательный состав экрана помимо трёх пунктов и кнопки — есть ли требование к заголовку, `AppBar` или его отсутствию? [Gap, Spec §FR-003, §FR-004]
- [x] CHK002 Определён ли язык, на котором показывается онбординг при самом первом запуске, когда пользователь ещё не выбирал язык в Настройках? [Gap, Spec §FR-009]
- [x] CHK003 Определена ли тема (светлая/тёмная), применяемая на первом запуске до любого выбора пользователя? [Gap, Spec §FR-009]
- [x] CHK004 Зафиксирован ли фактический текст метки действия продолжения, или «например, "Начать"» остаётся примером? [Clarity, Spec §US1 Acceptance 2, §FR-003]
- [x] CHK005 Заданы ли требования к ориентации экрана (портрет/ландшафт) и к минимальному поддерживаемому размеру экрана? [Gap, Coverage]

## Requirement Clarity

- [x] CHK006 Квантифицировано ли «кратко объяснять» — есть ли верхняя граница объёма текста, или это остаётся оценочным? [Ambiguity, Spec §FR-004]
- [x] CHK007 Задан ли предел увеличения системного шрифта, до которого требование «текст не обрезается» считается обязательным (например, ×2)? [Clarity, Spec §FR-010, §SC-004]
- [x] CHK008 Определено ли, что значит «действие продолжения доступно сразу» — только «не заблокировано», или ещё и «видно без прокрутки»? [Ambiguity, Spec §FR-003, §US2 Independent Test]
- [x] CHK009 Задан ли обязательный порядок следования пунктов (a)/(b)/(c), или он свободен? [Completeness, Spec §FR-004]

## Requirement Consistency

- [x] CHK010 Согласуются ли SC-002 («без необходимости прокручивать») и FR-010 (читаемость при увеличенном шрифте, что практически требует прокрутки содержимого)? [Conflict, Spec §SC-002, §FR-010]
- [x] CHK011 Согласовано ли требование «единственный экран» с допущением о возможной иллюстрации/анимации — не может ли оформление превратить экран в прокручиваемый тур? [Consistency, Spec §FR-003, §Assumptions]

## Acceptance Criteria Quality

- [x] CHK012 Можно ли объективно проверить SC-002 («одно касание, без прокрутки и ожидания») — задан ли наблюдаемый критерий, а не ощущение? [Measurability, Spec §SC-002]
- [x] CHK013 Сформулирован ли SC-004 так, чтобы каждый его пункт проверялся отдельно (screen reader, тап-таргет, крупный шрифт), а не как общее «доступно»? [Measurability, Spec §SC-004]

## Non-Functional (Accessibility)

- [x] CHK014 Заданы ли требования к доступности для нетапабельных элементов — читается ли screen reader'ом весь текст пунктов, а не только кнопка? [Coverage, Spec §FR-010]
- [x] CHK015 Определено ли требуемое поведение фокуса при открытии экрана (куда попадает фокус screen reader'а первым)? [Gap, Coverage]
- [x] CHK016 Указан ли конкретный минимум тап-таргета в самой спеке, или он подразумевается ссылкой на общие правила проекта? [Traceability, Spec §FR-010]

## Dependencies & Assumptions

- [x] CHK017 Проверено ли допущение, что оформление (иллюстрация, анимация) не создаёт функциональных требований — например, обязательного времени загрузки ассетов до появления кнопки? [Assumption, Spec §Assumptions]
- [x] CHK018 Задокументирована ли зависимость текстов онбординга от существующей структуры локализации (три языка, шаблонный файл), включая требование полноты перевода? [Dependency, Spec §FR-009]
